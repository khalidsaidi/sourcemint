Verify

Don't take our word for it

SourceMint claims that every SRCMNT token leaving a project wallet is recorded in a public ledger with a stated reason. This page checks that claim in your browser, against the Base blockchain, right now.

Nothing here is served from our machines. Your browser fetches the ledger from the repository and reads the chain through a public Base RPC endpoint. No account, no API key, nothing to install — and nothing we could quietly change without the chain disagreeing.

What this checked

Each ledger entry names a transaction. For every one, your browser fetched the transaction receipt from Base and confirmed it succeeded and carries a matching SRCMNT transfer of exactly that amount to exactly that address. It then read the live balance of each project wallet and the total supply, and confirmed they are what the ledger implies — to the last unit, in integer arithmetic.

That proves every claim in the ledger is real. It does not, on its own, prove there is nothing missing from it.

Prove nothing is missing

For that, the full history has to be derived from the chain rather than read from the ledger. Your browser can do that too. An account's nonce only ever increases, so searching it over block height finds every block in which a project wallet sent a transaction — nothing can hide there. The logs in those blocks are then read directly.

It takes a few hundred requests and under a minute. Same method the weekly check runs.

Doing it yourself instead

This page is a convenience, and you have no reason to trust a page we wrote. The same check runs from a clone of the repository, in Python, with no dependencies:

BASE_RPC_URL=https://mainnet.base.org python3 script/verify_ledger.py

How it works is written up in Make the build fail when the treasury moves, and the method is documented in verification.md.
